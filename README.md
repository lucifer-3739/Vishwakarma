# Vishwakarma Puja 2026 Web Invitation

An elegant, modern, and responsive single-page web invitation for **Vishwakarma Puja 2026**, hosted by **Ram Sharma**. Blends traditional Indian cultural elements (saffron, gold accents, marigold garlands, sacred mandala/gear motifs) with modern corporate UI aesthetics.

---

## 📅 Ceremonial Schedule

- **Day 1: Thursday, September 17, 2026**
  - `09:30 AM` — **Vishwakarma Puja & Sthapana** (Sacred invocation & tool blessing)
  - `10:15 AM` — **Vishwakarma Homa & Aarti** (Sacred fire ritual & Pushpanjali)
- **Day 2: Friday, September 18, 2026**
  - `06:00 PM – 06:30 PM` — **Vishwakarma Visarjan** (Immersion procession & farewell blessings)

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS v4
- **Typography**: Cinzel, Playfair Display, Plus Jakarta Sans (via `next/font/google`)
- **Icons**: Lucide React

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
